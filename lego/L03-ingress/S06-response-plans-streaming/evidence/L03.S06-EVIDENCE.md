## 2. Invariants & Proof of Conformance
1. **Immediate Ack vs Synchronous Completion**:
   - Manages state domain `pending-response-waiters` (alias `response-plan-registry`).
   - Dispatches decoupled immediate 200/202 responses for fire-and-forget webhooks without holding downstream thread pools.
   - Holds stateful synchronous waiters for workflows needing custom respond node outputs.
2. **Progressive Streaming Chunk Delivery**:
   - Dispatches streaming responses chunk-by-chunk with sequence ordering and final chunk termination flag.
   - Preserves content-type headers (e.g. `text/event-stream` for LLM integrations, binary octet streams).
3. **Fail-Closed Timeout Sweeping**:
   - Automatically sweeps expired waiters past their deadline and transitions them to `TimedOut` (HTTP 504 Gateway Timeout).
4. **Transport-Neutral Port Contract**:
   - Implements provided ports `port.ingress.response.stream.v1` and `port.ingress.response.plan.v1`.
   - Requires storage binary stream via `port.storage.binary.stream.v1`.
   - Rejects unauthorized invocations via security context scope validation.
5. **Boundary Isolation**:
   - 0 private cross-Sub-LEGO imports. All communication via typed public ports and `n8n-port-contract`.
