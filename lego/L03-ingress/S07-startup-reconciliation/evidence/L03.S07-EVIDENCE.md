   - Manages state domain `reconciliation-markers` (alias `ingress-recovery-ledger`).
   - Reconciles persisted active trigger definitions from `L05.S01` with active ingress routes on `H01`.
2. **Orphaned Trigger Detection**:
   - Accurately detects active triggers in persistence that lack a route entry on gateway hosts (due to crashes, restarts, or partition).
   - Generates deterministic `RegisterMissingEndpoint` actions to restore ingress routing.
3. **Zombie Route Eviction**:
   - Detects routes lingering in gateway memory whose corresponding workflows were deleted or disabled offline.
   - Generates deterministic `EvictZombieEndpoint` actions fail-closed.
4. **Startup Recovery Audit Ledger**:
   - Records every reconciliation action as an audit marker with status (`Pending` -> `Applied` / `Failed`).
5. **Transport-Neutral Port Contract**:
   - Implements provided ports `port.ingress.reconcile.execute.v1` and `port.ingress.reconciliation.sync.v1`.
   - Requires activation list via `port.ingress.activation.list.v1` and persistence load via `port.storage.persistence.load.v1`.
   - Rejects unauthorized invocations via security context scope validation.
6. **Boundary Isolation**:
   - 0 private cross-Sub-LEGO imports. All communication via typed public ports and `n8n-port-contract`.
