## Invariants Verified & Enforced
1. **Secret & Credential Sanitization**: Enforces strict fail-closed redaction of credentials during export, blocking any bundle containing unmasked API keys or passwords.
2. **Deterministic Manifest Validation**: Cryptographic manifest checksums and environment target assertions guarantee that bundles cannot be mistakenly deployed to mismatched tiers.
3. **Multi-Stage Promotion & Rollback**: Supports atomic promotion transitions (`Draft` -> `Exported` -> `Validated` -> `Imported`) with reversible rollback safety.
4. **Transport-Neutral Port Contract**: Provides `port.storage.promotion.export.v1`, `import.v1`, and `promote.v1` for CI/CD and multi-environment orchestration.
5. **Fail-Closed Security Boundary**: Invocations omitting valid principal, tenant, or authority scope are denied with `PortStatus::SecurityDenied`.
