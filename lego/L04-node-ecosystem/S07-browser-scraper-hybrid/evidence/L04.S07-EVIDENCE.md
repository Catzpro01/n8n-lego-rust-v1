## Invariants Verified & Enforced
1. **Isolated Session Pooling**: Headless browser instances are partitioned by session identifiers, managed with leased/idle/terminated states, and bounded by max pool capacity (`PoolCapacityExceeded`).
2. **Deterministic Lifecycle & Eviction**: Stale or terminated browser sessions are systematically pruned according to configured TTL parameters without memory or handle leaks.
3. **Structured Rendering & DOM Extraction**: Supports full HTML capture, screenshot capture, DOM selector waits, and targeted attribute/text extractions.
4. **Transport-Neutral Port Contract**: Exposes both `port.node.browser.render.v1` and `port.node.browser.hybrid.v1` for worker invocation pipelines.
5. **Fail-Closed Security Boundary**: Malformed URLs, unauthorized invokers, or empty execution payloads are rejected with explicit error codes.
